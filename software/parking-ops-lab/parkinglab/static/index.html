如何理解这些结果
冲突涉及率是实际占用重叠请求占已接纳请求的比例，每轮每个请求最多计一次。95% 界限采用仿真轮次层面的 Hoeffding 界，仅表示抽样误差。正态到离场偏差相互独立，泊位同质，未模拟冲突后的排队与重排。较低的冲突可能来自拒绝更多请求，应同时比较接纳权重和收入。仿真没有证明现实因果效果。

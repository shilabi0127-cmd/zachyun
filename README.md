# mobility-lab

Experiments with transport models and local inference. Python 3.12.

- [`parking-ops-lab`](software/parking-ops-lab) — booking allocation, MILP and simulation.
- [`local-research-kit`](software/local-research-kit) — SQLite note retrieval, local generation and quote checks.
- [`choice-model-lab`](software/choice-model-lab) — conditional logit, grouped holdout and cluster-robust errors.

Each directory has its own dependencies, tests and sample output. Inputs shipped here are synthetic or written specifically for the examples. Model weights stay outside the repository.
